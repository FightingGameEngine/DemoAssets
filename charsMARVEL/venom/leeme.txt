Venom  es como muchos sabreis, es como el reverso de spiderman, el echa la culpa de que todo
lo malo que le pasa es por spiderman. Este personaje tiene poderes parecidos a spiderman
dichos poderes se los da un simbionte, que como Venom comparte un odio especial hacia 
spiderman. El simbionte y la musculatura de Erick Brock hacen de este personaje un enemi
go temible.

Una vez hecha esta introduccion paso a detallar lo que posee este personaje para mugen:

Este personaje esta sacado del juego Marvel Capcom  que para mi uno de los mejores juegos de cap
com.

                          **Levantarse Rapido**

***************************************************************************************
Venom tiene una peculiaridad y es que puede levantarse desplazandose para evitar enemigos
esta tecnica solo funcionara cuando estemos en el suelo, y simplemente dando a izquierda
o derecha para elegir el lugar donde queremos desplazarnos.

*******************************************************************************************
                                           Notas Finales 
*******************************************************************************************

Este personaje ademas de las tecnicas anteriormente dichas en si son dos personajes en uno y utili
za la tecnica de las paletas separadas, utiliza una paleta para los personajes y otra para las magias
ademas si apretamos a start + algun boton Venom se convertira en otro personaje llamado Carnage que 
tiene tecnicas diferentes con lo que el trabajo a sido doble. Carnage era un personaje oculto que 
podias escoger si pasabas a venom, este char es mas rapido y hace mas daño. Tambien este personaje tiene
bonificacion si haces el primer ataque, quitando mas. Ademas para terminar tiene un monton de sonidos que
te ayudaran a saber los niveles de magia y muchas cosas mas.
