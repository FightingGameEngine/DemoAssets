M.O.D.O.K by volzzilla, Pilgrim, and flammableking

This is the first official release. Any version anyone may have had before was leaked
out due to a series of unfortunate events. We thank you all for understanding that.

M.O.D.O.K stands for Mechanized Organism Designed Only for Killing

***Specials***

QCF X = Psionic Blast
QCF Y = Acid Gun
QCF Z = Rocket Fire

QCB X = Fire Gadget
QCB Y = Electric Gadget
QCB Z = Sonar Gadget

QCF A = Rolling Attack 1
QCF B = Rolling Attack 2
QCF C = Rolling Attack 3

QCB A = Analize Cube 1
QCB B = Analize Cube 2
QCB C = Analize Cube 3

QCF X (in the air) = Air Psionic Blast
QCF Y (in the air) = Ignition Burst
QCF Z (in the air) = Beam Projectile

QCB X (in the air) = Balls to the Wall 1
QCB Y (in the air) = Balls to the Wall 2
QCB Z (in the air) = Balls to the Wall 3

QCB A (in the air) = Electroshock 1
QCB B (in the air) = Electroshock 2
QCB C (in the air) = Electroshock 3

QCF A (in the air) = Falling Spike 1
QCF B (in the air) = Falling Spike 2
QCF C (in the air) = Falling Spike 3

Down, Down + A = Ground Pulse
Down, Down + B = Electro Grenades

Down, Down + A = Land Mine
Down, Down + B = Airships Drones
Down, Down + c = Electrical Air Mine

Foward, Back + X = Chemical Shield
Foward, Back + Y = Fire Shield
Foward, Back + Z = Electric Shield

Foward, Back + Any Kick = Spinlaser

Up + Up = Fly (Tap again to come down. Will do so automatically after time)


***Helpers***

X+A = Aim Helper 1 (Need 500 in the bar)
Y+B = Aim Helper 2 (Need 500 in the bar)
C+Z = Aim Helper 3 (Need 500 in the bar)


***Hypers***

F, D, DF (Foward, Down, Down Foward) + 2 Punches = Killer Illumination (Need 2000 in the bar; unblockable/unguardable grab move)
QCF 2 Punches = Hyper Psionic Blast (Need 1000 in the bar)
QCF 2 Kicks = Hyper Battering Ram (Need 1000 in the bar)
QCB 2 Punches = A.I.M Army Moto Attack (Need 2000 in the bar)
QCB 2 Kicks = A.I.M Army Attack (Need 2000 in the bar)
QCF Punch+Kick = Heavy Artillery (Need 3000 in the bar)
QCB Punch+Kick = Mindguided Drone (1000 power; Drone then controlable by player. Arrows move 
you around, Light P/K=fire downward, Medium P/K=fire diagonally, Hard P/K=fire horizontally)
